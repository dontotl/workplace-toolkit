# 검증 보고서 — 2026-09-18

검증 대상은 새 `workplace-toolkit` 배포 후보입니다. 실제 고객 PPT·회의자료는 테스트나 소스 배포에 넣지 않았습니다. 아래 실제 실행과 시나리오 검증을 구분합니다.

## 실제 번역

현재 Codex 세션이 공개 합성 영어 PPT 6장의 텍스트 37개를 한국어로 번역했습니다. 번역기는 별도 제공자 API나 API 키를 사용하지 않습니다.

- 제목·본문·굵게 강조한 run·표·그룹·긴 문장·이미지를 포함합니다.
- 원본 해시, ID 전체 포함, 보호 용어/숫자/단위/URL, 비대상 ZIP 멤버 보존을 검사했습니다.
- 원본 64개 ZIP 멤버 중 변경 대상은 슬라이드 XML 6개뿐입니다. 원본 파일, 노트, 미디어는 유지됩니다.
- LibreOffice로 로컬 렌더링하고 6개 화면을 독립 검토했습니다. 잘림·누락 글리프·의미 손실은 발견하지 못했습니다. 슬라이드 6은 우측 여백이 좁지만 내용은 보입니다.
- 매니페스트 v2는 보호 정책과 경고를 함께 해시로 연결합니다. 해시/정책 불일치, 누락/중복 ID, 변경된 수치, 하이퍼링크 run 밖으로 이동한 URL은 차단합니다.

로컬 증거: `artifacts/translation/`의 source.pptx, translations.json, manifest-v2.json, translated-v2.pptx, structural-v2.json, 렌더 PDF/PNG. 증거 디렉터리는 배포 ZIP에 포함되지 않습니다.

## 실제 로컬 음성·영상

공개 합성 문장 한 개로 새 발표 제작 코드를 실행했습니다.

| 항목 | 확인 결과 |
|---|---|
| 음성 | 로컬 Qwen3-TTS CustomVoice, Korean/Sohee, MLX/Metal |
| 중간 파일 | FLAC, mono 24 kHz, 8.32초, 약 158 KB; 유지되는 WAV 없음 |
| ASR | 로컬 faster-whisper CPU/int8, 한국어, 정규화 일치도 1.0, 경고 0개 |
| MP4 | 1920×1080, 30 fps, H.264/AAC, 9.375초, 171,487바이트 |
| 부가 정보 | mov_text 한국어 자막과 챕터 포함 |
| 무결성 | FLAC 해시 확인, ffprobe 및 전체 ffmpeg 디코드 통과 |

영상 길이는 음성 8.32초에 앞뒤 여백과 코덱 프레임 차이를 더한 값입니다. 45분 전체 발표를 새 패키지로 검증했다는 뜻은 아닙니다. CPU TTS 합성은 실행하지 않았습니다. 모델 로딩 시 토크나이저 정규식 호환 경고, ASR 런타임에서 로컬 telemetry ID 저장 경고가 발생했습니다. 경고를 기록했으며 모델·기존 런타임을 수정하지 않았습니다. 네트워크 패킷 감사를 수행한 것은 아닙니다.

로컬 최종 증거: `artifacts/media/sample-final.mp4`, 동명의 SRT/챕터/검증 JSON, `tts-smoke/`의 FLAC와 ASR 보고서. 최종 검증 JSON은 출력 해시/크기와 파일명만 기록하며 임시 절대경로를 제거했습니다. 초기 `sample.*` 파일은 수정 전 비교용 증거로 보존했으며 최종 메타데이터 검증 대상이 아닙니다. 실제 음성의 자연스러움/발음은 ASR 일치도만으로 보증하지 않으며 사람이 들어봐야 합니다.

## 연구·보고 스킬 행동 검증

- 연결되지 않은 Slack/SharePoint에서 검색한 척하지 않았습니다.
- 다운로드 권한 거부를 우회하거나 출처 불명 복사본으로 대체하지 않았습니다.
- 합성 회의 메모와 지정된 JSON 이력만으로 20개 필드를 보존한 보고서를 만들었습니다. 관련 Opportunity를 근거와 함께 재사용하고 미확인 참석자/일시는 확인 필요로 남겼습니다.
- local-only 자료를 원격 모델에 읽히지 않는 경계와, 내용을 노출하지 않는 로컬 적용/구조 검증을 구분했습니다.

이 항목들은 통제된 시나리오 테스트입니다. 다른 사용자의 실제 Slack/SharePoint 테넌트 연결이나 다운로드 성공을 검증한 것은 아닙니다. 각 사용자의 승인된 커넥터/브라우저가 필요합니다.

## 자동 검증과 이식성

최종 통합 실행: **38개 테스트와 7개 하위 사례 통과**. 구성은 번역 17개, 발표 제작 15개, 설치/배포 6개입니다. 별도 설치본에서 저장소 밖 작업 디렉터리로 이동해 번역·발표 테스트 **32개와 7개 하위 사례**를 다시 통과했고, 두 CLI의 도움말 실행도 성공했습니다. 네 스킬과 플러그인 형식 검증을 모두 통과했습니다. 독립 리뷰의 중요 지적 사항을 회귀 테스트로 재현한 뒤 수정·재검수했습니다.

6장 실제 합성 PPT의 기존 노트 모드도 실행해 출력이 원본과 바이트 단위로 동일함을 확인했습니다. 실제 Sohee FLAC의 이전 매니페스트를 새 체크포인트로 이전하고 재생성 없이 재사용했으며 파일 해시가 유지되었습니다.

다음 명령으로 배포 코드의 전체 테스트를 재실행합니다.

```bash
.venv/bin/python -m pytest tests skills/ppt-translator/tests skills/presentation-studio/tests -q
python3 scripts/distribution.py scan
```

별도 설치 경로로 네 스킬을 복사한 뒤 실행 경로가 저장소 루트에 의존하지 않는지 검사합니다. 스킬/플러그인 형식은 Codex 제공 검증기로 확인합니다. 기존 설치본을 덮어쓰지 않으며, 개별 스킬마다 MIT LICENSE를 포함합니다.

실측 운영체제는 macOS/Apple Silicon입니다. Windows/Linux 명령과 UTF-8/하드링크 미지원 경로를 제공하지만 해당 OS의 전체 실제 실행이나 새로운 사용자의 Codex 자동 발견까지 검증했다고 주장하지 않습니다. 모델 가중치·커넥터·운영체제 의존성은 별도 준비 사항입니다.

## 남은 한계

- 번역되지 않는 이미지·차트·SmartArt·필드·마스터/레이아웃은 경고와 화면 검수 대상입니다. 마스터/레이아웃 경고에는 사용하지 않는 템플릿 안내 텍스트도 포함될 수 있습니다.
- 수치 검증은 흔한 형식을 보호하는 보조 장치입니다. 회계식 괄호 음수, 특수 통화 배치와 문장 의미는 사람이 확인해야 합니다.
- 변경 없는 대용량 미디어는 스트리밍하지만 OOXML 텍스트 부분은 메모리에 파싱합니다. 악성 파일 전용 격리·ZIP 폭탄 방어 시스템은 아닙니다.
- `.ppt` 로컬 변환의 오류 처리는 테스트했으나 실제 레거시 `.ppt` 변환 샘플은 검증하지 않았습니다.
- 정적 슬라이드 렌더만으로 PPT 애니메이션을 복원하지 않습니다. 이동 영상은 명시적으로 준비된 로컬 자산만 사용합니다.
- 비밀정보 정규식 스캔은 완전한 DLP/IP 심사가 아닙니다. 공개 전 회사 권리·자료 검토가 필요합니다.
