# 구성과 처리 경계

네 스킬은 각각 독립된 `SKILL.md`, 참조 문서, 필요한 실행 코드, MIT `LICENSE`를 포함합니다. 공통 플러그인은 같은 디렉터리를 가리키는 선택형 포장입니다. 특정 MCP 서버나 작성자의 Codex 설정을 함께 복사하지 않습니다.

| 스킬 | Codex 역할 | 로컬/연결 도구 역할 |
|---|---|---|
| workplace-research | 범위 설정·출처 비교·근거 정리 | 승인된 소스 검색·명시적으로 요청된 다운로드 |
| ppt-translator | 현재 승인된 세션에서 문맥별 번역·의미 검수 | OOXML 추출·해시 검증·텍스트 반영·로컬 렌더링 |
| visit-call-report | 지정 이력과 메모로 보고서 작성 | 사용자 선택 파일 읽기·Markdown 저장 |
| presentation-studio | 전체 주제·챕터·대본 설계 또는 기존 노트 준수 | 노트 관리·로컬 TTS·FLAC 캐시·ASR·MP4 |

## 번역 파이프라인

`원본 PPTX → manifest.json → 현재 Codex의 translations.json → 새 PPTX → 구조·화면 검수`

원본 해시와 매니페스트 해시가 번역문에 연결됩니다. 텍스트 노드 ID를 빠짐없이 확인하고, 부호·통화·숫자 순서·단위·URL·보호 용어를 검사합니다. 해시는 파일 혼용/누락을 막는 장치이지 작성자 인증은 아닙니다. 문맥의 정확성은 별도 언어 검수가 필요합니다. 이미지·차트·SmartArt·마스터/레이아웃 등의 미지원 텍스트는 숨기지 않습니다.

## 발표 제작 파이프라인

`PPTX → 물리적 슬라이드 순서/노트 → 승인된 대본 → 로컬 Sohee FLAC → 로컬 ASR 검수 → 렌더된 화면 + MP4/SRT/챕터`

대본, 모델 내용, 음성 설정이 캐시 키에 반영됩니다. 영상 길이는 실제 음성 길이로 결정되며, 목표 시간에 맞춘 강제 배속은 하지 않습니다. 정적 PNG만 있으면 애니메이션이 보존됐다고 주장하지 않습니다. 움직임은 명시적으로 제공된 로컬 영상만 사용합니다.

## 배포

`scripts/distribution.py`는 전역 설정을 바꾸지 않고 사용자가 지정한 위치에 스킬을 설치합니다. 기존 이름이 있으면 중단합니다. 소스 ZIP에는 고객 자료·산출 영상·모델·가상환경·인증정보를 넣지 않습니다. 각 수신자는 자신의 승인된 연결 도구와 로컬 모델/런타임을 준비합니다.

하드링크 지원 파일시스템에서 번역/압축파일 게시가 원자적입니다. 미지원 파일시스템에서는 배타적 생성/복사를 사용해 덮어쓰기를 막지만 복사 도중 가시성까지 원자적이지는 않습니다. 실패한 복사본은 제거하며 원본은 유지합니다.
